# Public source review copy

This is an intentionally incomplete, privacy-filtered copy of the local project workspace.
It contains frontend and local desktop application source. Differing source from parallel
working folders is retained under `archive/worktree-snapshots/` with its original relative
layout. These variants are references, not automatically merged applications.

The owner explicitly accepts that omitted material can prevent projects from loading.
Backend implementations, server projects, infrastructure/deployment configuration, internal
history and operating instructions, nightly material, private paths/identities, credential
patterns, generated diagnostic data, and all media/binaries are omitted. Some harmless
files can also be omitted by conservative screening. Original working folders are unchanged.

See `UPLOAD_SCOPE.json` for aggregate inclusion and omission counts. The detailed file-by-file
audit is retained locally outside this repository because it contains original private paths.
The scan checks known identity terms, machine paths, email addresses, credential patterns,
server signatures and file/directory categories. It is screening, not a proof that arbitrary
source text can never contain private information. Application tests were not run on this
deliberately incomplete copy. Do not use it as a deployment source.

This review copy has a fresh Git history. No original commit authors or original historical
objects are included. Replacing remote branches does not itself guarantee removal of GitHub
cached commits or internal pull-request references. Those require separate verification before
a repository containing earlier private material is made public.

Retained third-party notices do not choose a license for the owner's application source.
No executable, model, engine, encoder, third-party creative asset or optional dependency cache
is included. No production deployment is part of publishing this source snapshot.
