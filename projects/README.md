# Projects

New editable work goes in projects/<slug>/. [Portfolio](portfolio/README.md) is the first canonical source here. Legacy active games and prototypes retain their paths listed in [workspace map](../docs/WORKSPACE.md); do not create competing editable copies for them.

A new project's README must explain purpose/status, owner, source versus generated output, preview/build/test entry points, original asset provenance and release location. Add the project to workspace-map.json. Backend services still use the existing banderov/ deployment project unless a separate architecture change is explicitly agreed.
