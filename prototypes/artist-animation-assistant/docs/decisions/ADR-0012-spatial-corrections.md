# ADR-0012 — Shared spatial masks and literal repair gestures

Date 2026-10-21 00:27 EDT. Full artist-assistance goal active.

Use immutable tiled PixelPlane for explicit boolean correction flags, tagged
red-boolean-mask-1. Red0/1/other bytes0, including alpha0; do not pass through a
renderer or normalizing PNG serializer. Existing raw tile content IDs/dedup/indices
provide shared history and bounded state. This is not a1bitstorage claim. Keep
legacy list/unknown-locked fallback, bounded region materialization and no automatic
constraint release. Explicit artist stroke may revise old protected pixels; assistant
generation must respect masks. Validate outside-touch equality before commit.

Independent capsule distance follows literal pointer samples, radius fixed for a
gesture, hard replacement pixels. No intended curve, pressure or texture inferred.
Preserve accepted constraint geometry under known integer shifts, but refuse
protected clipping at worker/acceptance. Pure non-destructive proposal exploration
still possible with warning; preserving that existing source-safe contract fixed
unit03regression. Intentional off-canvas motion requires later visibility/anchor
representation, not a claim that conservative refusal completes animation.

100dense native strokes/101versions demonstrate this foundation beyond pixel points,
not artist task usefulness. Selected-ROI cleanup/fill is next; do not grow a generic
painting replacement or procedural-only goal. All rights-cleared model approaches
remain eligible when unresolved contour/texture/semantic failures warrant them.
