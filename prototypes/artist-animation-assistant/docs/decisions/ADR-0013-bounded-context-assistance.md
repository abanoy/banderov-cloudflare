Accepted 2026-10-21 00:48 EDT. Full master remains active. Prior storage/masks are enabling work.

Use an explicit <=224square output rectangle and16pixel halo to reuse attributed
<=256local algorithms. Preserve raw source/outside/holds/approvals, map world/local
coordinates and typed spatial constraints. Selection is output extent, not semantic
closure. Warnings disclose sampled-edge leaks. Fixed context/scope are limitations.

Keep existing packed worker/recompute/review/local epochs and undo. Geometry masks
retain identity independent of displayed alpha/color. Preview actual editable group
composition, including opacity. White-paper separation is local and cannot touch peer
managed coverage.0.1 remains unchanged. Current masks are RGBA tile assets, not1bit.

fill; silently treating a crop edge as an ink/anatomical boundary; metadata-only
reference influence; replacing semantic/construction work with indefinite diagnostics.

artist data/task benefit, global method, learned model or public deployment claim.
