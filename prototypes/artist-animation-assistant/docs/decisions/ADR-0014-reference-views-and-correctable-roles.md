# ADR-0014: Optional local views, correctable part and color-role identity

Accepted 2026-10-21 01:08 EDT. Complete master scope remains active.

Embed exact local PNG sources independently of drawing dimensions; annotations are
editable metadata. Separate character/part identity, selected view, color anchor and
accepted region geometry. Artist corrections outrank geometric proposals. Use
independent normalized-box distance as a declared baseline while semantic inference
is researched. Preserve unknown/ambiguous alternatives, no calibrated probability.

Use view-scoped named color roles to avoid cross-view recolor, while semantic part
IDs remain stable. Existing shared palettes update bound members; optional propagation
is explicit and excludes other characters/known different views. Protect raw artist
RGBA and keep old source versions. Retain immutable input crop/SHA/revision/anchors
in accepted operations. Reference removal keeps original source for provenance.

Local project use does not authorize training/upload. BasicPBC paper/README/license
are research evidence only; its code/weights/data are not acquired, executed or cleared
for this distribution. Other rights-cleared neural/procedural routes remain eligible.

Evidence174unit/235own-native checks,12original variants/36decisions. Wrong views and
anchors fail; ID correctness and displayed color differ. No representative artist
benchmark or automatic pose/anatomy inference. Next correspondence/deformation/
visibility and genuinely useful drawing schedules, not indefinite generic-painter work.
