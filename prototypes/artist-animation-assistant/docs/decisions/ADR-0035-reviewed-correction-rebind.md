# ADR0035 — Explicit reviewed retained-correction rebind

Status: scoped core/worker/private CLI verified; selected standalone controls pending.

When a source, phase or generator changes, old masks must not silently move or vanish.
Keep the chosen old version, privately disable only its active binding, recompute a
fresh unapproved target, and preview an explicitly supplied integer placement. Reject
marked clipping, conflicting protected pixels and undeclared actor/layer mapping.

Strict review recomputes and verifies exact affected scope, raw/model output,
comparison and prepared constraints. Accept constraints only, retain old history,
preserve independent source edits, and support one Session commit/undo. Existing
background owned-process deadline/cancel/storage/provenance contracts are reused.

This is not semantic correspondence or an automatic quality improvement. Add explicit
old/raw/mapped selected-host controls next. Preserve the full master specification,
future richer mapping and every native/rough/semantic/artist-usefulness requirement.
Evidence: EXP0039results/verification and private actual-study diagnostic.
