DON BASS CRUSADERS: BUILD CASTLES & BATTLE! - local preview (map: The Floating Aerie)
Extract the complete ZIP, run python serve.py, and open http://127.0.0.1:8805/ . Python 3 is required. No internet assets. If port 8805 is busy, run python serve.py 8806 and open http://127.0.0.1:8806/ instead.
Start from the title screen: Quick Battle, Custom Battle, Castle Workshop, Crusader (dress your character), Explore the Aerie, Settings, How to Play (every key and its touch control) and Stats (kept for this browser session; Banderov accounts are a placeholder, not connected).
In a match: WASD/arrows walk or steer the pod; Space launches from a glowing pad; left click fires; 1-6 choose a weapon; T reloads; V restocks; Q/E rotate; the wheel zooms; P or Esc pauses. Phones and tablets get on-screen controls.
The Original sketch link is available on the full development server only, not this separate package.
