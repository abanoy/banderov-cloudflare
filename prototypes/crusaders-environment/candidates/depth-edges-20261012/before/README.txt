THE FLOATING AERIE - local preview
Extract the complete ZIP, run python serve.py, and open http://127.0.0.1:8805/ . Python 3 is required. No internet assets.
WASD/arrows move and steer; Q/E rotates; wheel zooms; choose destination then Launch Pod/Space. Gravity creates the arc. Missing an island returns to the castle.
The Original sketch link is available on the full development server only, not this separate package.
