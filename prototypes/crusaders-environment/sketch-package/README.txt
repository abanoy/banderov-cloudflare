CRUSADERS FORTRESS - LOCAL REVIEW BUNDLE

Extract the ZIP into its own folder. Python 3 is required for the included
local preview helper. In that folder run: python serve.py
Then open http://127.0.0.1:8798/ in your browser. Ctrl+C stops the helper.
If port 8798 is already in use, use another local HTTP server for this folder.
Opening index.html directly as a file may block browser module imports.

No account or internet connection is required for the rendering assets.
Saved sliders are local to the browser and address where you open this copy.
The source modules are included and editable. Three.js licence is in vendor/.

Choose Walk route to explore with WASD/arrows or the on-screen movement pad.
On touch screens, hold the pad with one finger and drag the scene with another
to turn. Stop walking returns to inspection. Lighting and pixelation sliders
remain available above the scene; Save sliders keeps them in this browser.

This snapshot includes the sketch fortress, placeholder billboard and
optional lighting study. It does not include the separate pod-flight or
pinned 3D-character demos. Only the marked walk corridor is supported.
The original sketch and historical screenshots are omitted from this runtime
bundle; the workspace review keeps those references.
